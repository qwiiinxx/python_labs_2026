# Лабораторная №7  
## Консольное приложение - **Агентство недвижимости**

---

# 1. Цель работы

В данной лабораторной работе было реализовано полноценное консольное приложение (CLI) на основе всех предыдущих лабораторных работ.

В работе были объединены:

- объектно-ориентированное программирование
- наследование
- коллекции объектов
- интерфейсы
- стратегии
- generics и typing
- обработка исключений
- работа с файлами
- консольный интерфейс

---

# 2. Структура проекта

## `main.py`

Точка входа в приложение.

Запускает CLI-интерфейс.

---

## `cli.py`

Файл пользовательского интерфейса.

Отвечает за:

- вывод меню
- ввод пользователя
- обработку команд
- обработку ошибок ввода

---

## `app.py`

Слой бизнес-логики приложения.

Содержит:

- работу с коллекцией
- поиск объектов
- сортировку
- фильтрацию
- добавление и удаление объектов

---

## `models.py`

Содержит модели недвижимости:

- `Apartment`
- `House`
- `PentHouse`

Используются классы из ЛР-3.

---

## `exceptions.py`

Содержит собственные исключения:

- `DuplicateItemError`
- `ItemNotFoundError`
- `InvalidMenuChoiceError`

---

## `storage.py`

Файл для работы с JSON.

Реализует:

- сохранение коллекции
- загрузку коллекции

---

# 3. Описание CLI

## Главное меню

Реализованы пункты:

1. Добавить квартиру
2. Показать все объекты
3. Найти объект по цене
4. Удалить объект
5. Сортировка по цене
6. Показать только активные
7. Показать только аренду
0. Выход

---

## Работа приложения

Приложение работает в бесконечном цикле:

- после каждого действия меню показывается снова
- пользователь может выполнять операции многократно

---

## Обработка ошибок

Реализована обработка:

- ввода строки вместо числа
- неверного пункта меню
- удаления несуществующего объекта
- добавления дубликатов

Используются:

- `try`
- `except`
- собственные исключения

---

## Сохранение данных

При работе используется JSON-файл.

Реализованы:

- `save()`
- `load()`

---

## Сортировка

Реализована сортировка:

- по цене
- по площади

---

## Фильтрация

Реализована фильтрация:

- только активных объектов
- только объектов для аренды

---
