# Лабораторная №5  
## Функции как аргументы. Стратегии и делегаты - **Недвижимость**

---

# 1. Описание реализованной системы

В лабораторной была расширена коллекция недвижимости `Agency` из ЛР-2.

Добавлена поддержка:

- передачи функций как аргументов
- стратегий сортировки
- стратегий фильтрации
- map / filter
- lambda-выражений
- callable-объектов
- цепочек операций

---

## Назначение

Коллекция теперь умеет:

- сортировать объекты разными способами
- фильтровать по произвольным условиям
- применять функции ко всем объектам
- использовать стратегии без изменения кода коллекции

---

# 2. Реализованные стратегии

## Файл `strategies.py`

В отдельный файл были вынесены все функции и стратегии обработки объектов.

---

## Стратегии сортировки

### `by_price()`
Сортировка по цене объекта

### `by_area()`
Сортировка по площади объекта

### `by_per_meter()`
Сортировка по цене за квадратный метр

---

## Функции-фильтры

### `is_expensive()`
Фильтрация дорогих объектов (> 30 млн)

### `is_cheap()`
Фильтрация дешевых объектов

### `is_for_rent()`
Фильтрация объектов только для аренды

### `is_active()`
Фильтрация только активных объектов

---

## Фабрика функций

### `make_price_filter(max_price)`

Создает и возвращает новую функцию-фильтр
с заданным максимальным порогом цены.

---

## Функции для `map()`

### `get_price()`
Возвращает цену объекта

### `to_str()`
Преобразует объект в строку

---

# 3. Callable-объекты (паттерн Strategy)

## `DiscountStrategy`

Стратегия применения скидки к объекту.

Используется метод:

`__call__()`

Объект класса можно вызывать как функцию.

---

## `TaxStrategy`

Стратегия применения налога к объекту.

Также реализована через `__call__`.

## Цепочка операций

    .sort_by(by_price)
    .apply(TaxStrategy(10))
