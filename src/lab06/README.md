## Generics и typing — **Типизированная коллекция недвижимости**

# 1. Описание Generic-контейнера и typing

В лабораторной работе реализована система типизированных коллекций для объектов недвижимости.

Использованы:

- `TypeVar`
- `Generic`
- `Protocol`
- аннотации типов
- функции `find`, `filter`, `map`

---

## Назначение

Типизированная коллекция позволяет:

- хранить объекты определенного типа
- безопасно работать с объектами
- использовать подсказки IDE
- применять функции к коллекции
- фильтровать и искать объекты
- использовать структурную типизацию через `Protocol`

---

# Generic-класс

## `TypedCollection[T]`


Реализованные методы
Управление объектами


add() — добавление объекта


remove() — удаление объекта


get_all() — получение списка объектов



Поиск и обработка


find() — поиск первого подходящего объекта


filter() — фильтрация объектов


map() — преобразование объектов



TypeVar
Использованы типовые переменные:
T = TypeVar("T")R = TypeVar("R")

Для чего нужен T
T обозначает тип объекта внутри коллекции.
Например:
TypedCollection[Apartment]
означает:


внутри могут храниться только Apartment



Для чего нужен R
R используется в map().
Позволяет менять тип результата.
Например:
list[str]list[float]

Protocol
Реализованы два Protocol:

Displayable
class Displayable(Protocol):    def display(self) -> str:
Объект обязан иметь метод:
display()

Scorable
class Scorable(Protocol):    def score(self) -> float:
Объект обязан иметь метод:
score()

Структурная типизация
Классы:


Apartment


House


PentHouse


НЕ наследуются от Protocol напрямую.
Но подходят под них автоматически,
потому что имеют нужные методы.
Это и есть:
структурная типизация

Ограниченные TypeVar
Созданы специальные ограничения:
D = TypeVar("D", bound=Displayable)S = TypeVar("S", bound=Scorable)

Что это дает
Теперь можно создавать коллекции:
TypedCollection[D]
где разрешены только объекты,
имеющие метод display().

Методы display() и score()

display()
Возвращает красивое описание объекта.
Пример:
Квартира: Арбат 15, 2 комнаты

score()
Возвращает числовую оценку объекта.
Например:
цена за квадратный метр
